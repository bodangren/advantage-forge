# Bathhouse mockups

Concept mockups for the 3 bathhouse props of the trial track
`measure/archive/asset_hy4_maker_trial_20261116/`.

| File | Prop | Size |
| --- | --- | --- |
| `towel-stack-mock.jpg` | A stack of 3 folded towels for a shelf board | 0.30 x 0.24 x 0.22 m |
| `wash-basin-mock.jpg` | A staved wooden wash basin with water and a dipper | 0.42 m across, 0.17 m tall |
| `towel-rack-mock.jpg` | A small wooden stand with towels hung on it | 0.62 x 0.34 x 0.82 m |

The files come from `mmx image generate` on the MiniMax Token Plan. The style follows
`docs/item-mockups/`: one prop, soft bevels, a warm palette, a plain background, and a three-quarter
view from slightly above.

The mockups are style ideas, not traces. Each brief in the track folder is the design contract. The
maker matches the idea and the colors of the mockup, not every detail.

The 3 props are not catalog rows of the Chibi Quest pack. They come from the towel follow-up of
`measure/tracks/asset_filled_shelves_20261028/`.
