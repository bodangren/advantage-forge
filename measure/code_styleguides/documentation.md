# Documentation guide

The Measure index is the entry point for project management.

- Record execution status in the owning track plan.
- Update track metadata and registry markers together.
- Cite commits, files, commands, and observed results.
- Distinguish current verification from historical delivery.
- Preserve existing design paths and catalog identifiers.
- Request approval before changing a path that callers or tools depend on.
- Keep lessons and debt within 50 lines each.
- Move detailed evidence into track files or the evidence directory.
- Use active voice and simple verb tenses.
- Keep descriptive sentences within 25 words.
- Keep procedural sentences within 20 words.

Historical backfills use null estimates and actuals when original task counts are unknown.
Generated inventory counts do not establish acceptance.
