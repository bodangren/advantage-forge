# Migrate project management to Measure

## Purpose

Establish one indexed management system for asset production and game development. Backfill the rework without rewriting history.

## Acceptance criteria

- Every rework commit maps to a historical track.
- Every catalog target, scene blueprint, and game plan has an owning track.
- Status, dependencies, debt, lessons, and evidence resolve from the project index.
- Generation and structural checks detect stale facts and invalid links.
- Existing source, output, and design paths remain stable.
