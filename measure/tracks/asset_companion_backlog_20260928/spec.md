# Define companion media production

## Purpose

Define production plans for interface art, portraits, layered backgrounds, audio, music, fonts, and complete tile contracts.

## Acceptance criteria

- Each companion category has an owner role and a bounded production proposal.
- The proposal states which outputs derive from Forge sources.
- The proposal identifies licenses and game consumers.
- Approved production work receives separate tracks before implementation.
