# Chibi Quest goblin warrior mockup

[View the four-view turnaround](./chibi-goblin-warrior-turnaround.png). This is the Chibi Quest treatment of `enemies/humanoid/goblin-warrior`.

The goblin has a large round head, short limbs, wide ears, big eyes, and a playful grin. It keeps the shared identity cues from the [Riven Lands reference](../riven-goblin-warrior-20260925/README.md): a nicked left ear, one shoulder guard, a diagonal strap, a belt pouch, wrapped forearms, boots, and one short dagger.

The Chibi Quest version uses a brown tunic, red-orange scarf, tan leather, and soft blue-gray metal. Flat two-tone shading and a thick dark outline keep the form readable at small sprite sizes. The dagger is a separate equipment part with catalog ID `equipment/melee-weapons/dagger`.

This image is a visual reference, not a finished 3D model. The four views share one baseline and one character identity. Preserve the ear nick, strap, pouch, guard, and dagger when building the source model.
